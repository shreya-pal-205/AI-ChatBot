**🌟 Career Guidance Chatbot**
**Powered by RAG + Vite React + Node.js + Express + Vector Database**

A smart AI-powered Career Guidance Chatbot designed to help users explore career paths, required skills, job trends, and personalized recommendations.
This project uses a **Retrieval-Augmented Generation (RAG)** pipeline with a modern React (Vite) frontend and Node.js/Express backend connected to a Vector Database for fast semantic search.



**🚀 Features**

**🔍 RAG-based Career Assistant**<br>
Upload career-related documents or use preloaded knowledge base.<br>
Extracts relevant information using embeddings + vector similarity search.<br>
Generates accurate, context-aware responses.<br>

**🧠 AI-Powered Chatbot**<br>
Natural language conversation.<br>
Provides career suggestions, job roles, roadmap, courses, and guidance.<br>

**⚛️ Frontend (Vite + React)**<br>
Fast, optimized UI built with Vite.<br>
Chat interface with streaming responses.<br>
Responsive layout and attractive design.<br>

**🛰️ Backend (Node.js + Express)**<br>
API endpoints to receive queries.<br>
Performs embedding generation + vector search + LLM response.<br>
Uses CORS for secure frontend-backend communication.<br>

**📦 Vector Database**<br>
Stores embeddings of documents/topics.<br>
Provides fast semantic search.<br>
Supports similarity scoring for RAG.<br>
