**🌟 Career Guidance Chatbot**
**Powered by RAG + Vite React + Node.js + Express + Vector Database**

A smart AI-powered Career Guidance Chatbot designed to help users explore career paths, required skills, job trends, and personalized recommendations.
This project uses a **Retrieval-Augmented Generation (RAG)** pipeline with a modern React (Vite) frontend and Node.js/Express backend connected to a Vector Database for fast semantic search.



**🚀 Features**

**🔍 RAG-based Career Assistant**<br>
Upload career-related documents or use preloaded knowledge base.
Extracts relevant information using embeddings + vector similarity search.
Generates accurate, context-aware responses.

**🧠 AI-Powered Chatbot**
Natural language conversation.
Provides career suggestions, job roles, roadmap, courses, and guidance.

**⚛️ Frontend (Vite + React)**
Fast, optimized UI built with Vite.
Chat interface with streaming responses.
Responsive layout and attractive design.

**🛰️ Backend (Node.js + Express)**
API endpoints to receive queries.
Performs embedding generation + vector search + LLM response.
Uses CORS for secure frontend-backend communication.

**📦 Vector Database**
Stores embeddings of documents/topics.
Provides fast semantic search.
Supports similarity scoring for RAG.
